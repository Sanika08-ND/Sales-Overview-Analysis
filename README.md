<h1> Sales Overview Analysis Dashboard (Power BI)</h1>

<div class="section">
    <h2> Project Overview</h2>
    <p>This project presents a dynamic Sales Overview Dashboard built using Power BI to track and analyze key business metrics across multiple regions.</p>
    <ul>
        <li>Monitor Sales, Profit, and Quantity</li>
        <li>Compare Current Year (CY) vs Previous Year (PY) performance</li>
        <li>Analyze trends across Central, East, South, and West regions</li>
        <li>Interact with data using filters and dynamic metric selection</li>
    </ul>
</div>

<div class="section">
    <h2> Business Requirement</h2>
    <ul>
        <li>Tracks Sales, Profit, and Quantity</li>
        <li>Covers four regions: Central, East, South, West</li>
        <li>Allows year-based filtering</li>
        <li>Enables dynamic switching between KPIs</li>
        <li>Includes Year-over-Year (YoY) comparison</li>
        <li>Provides monthly trend analysis</li>
    </ul>
</div>

<div class="section">
    <h2> Key Features</h2>

   <h3>Regional Analysis</h3>
    <ul>
        <li class="highlight">Display of Sales, Profit, Quantity based on selected year</li>
        <li class="highlight">Dynamic KPI selection (Sales / Profit / Quantity)</li>
        <li class="highlight">Previous Year Sales comparison (PY)</li>
        <li class="highlight">Monthly bar sparkline with average line</li>
    </ul>

   <h3> Sales by State Analysis</h3>
    <ul>
        <li><b>Bubble Map:</b> Visualizes sales distribution across states</li>
        <li><b>Bar Chart:</b> Displays state-wise comparison</li>
    </ul>
</div>
